# IBC documentation has moved

The IBC docs now live at https://ibcprotocol.dev/docs, built from
https://github.com/cosmos/ibc/tree/main/docs. The ibc-go docs are at
https://ibcprotocol.dev/docs/ibc-go/latest, sourced from
https://github.com/cosmos/ibc/tree/main/docs/ibc-go.

All `/ibc/*` URLs on docs.cosmos.network redirect there. `/ibc/latest/*` maps
page for page: `/ibc/latest/spec/*` to `/docs/ibc/spec/*` and everything else
under `/ibc/latest/` to `/docs/ibc-go/latest/`. Other versions, including
`/ibc/next/` and the archived ones, land on the docs home.

The last state of this directory before removal, including every archived
version, is preserved here:

https://github.com/cosmos/docs/tree/d6038e7d119c6f0b934b6172dd15737d57be8ad9/ibc

Do not add content here. Open a PR against cosmos/ibc instead.
